Delivery demo -- post-mission data capture, upload, and customer delivery
========================================================================

  delivery status: delivered
  delivered to: ['acme-industrial']
  mock-customer server actually received: {'customer_id': 'acme-industrial', 'mission_id': 'mission-thermal-for-delivery', 'package_filename': 'mission-report-mission-thermal-for-delivery.zip', 'robot_id': 'spot-01'}

--- 2. Robot goes offline for the whole mission: mission itself fails, delivery is never attempted ---
  (DeliveryService.deliver() is only reachable through a COMPLETED mission -- the publicly
   reachable way to show 'data never makes it off the robot' is the mission failing outright;
   the UPLOAD_FAILED status itself -- a mission that completes but whose data upload separately
   fails -- is exercised directly in tests/test_data_delivery.py, which can force that exact
   split via a FaultProfile the public API has no way to toggle mid-mission.)
  mission final status: failed (module=comms, same retry policy, mission itself fails)
  delivery record: None (None -- deliver() is never called for a non-COMPLETED mission)
